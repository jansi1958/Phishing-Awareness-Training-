# Phishing Awareness Training

An interactive web-based training project that teaches users how to recognise, avoid and report phishing attacks. Built with plain HTML, CSS and JavaScript — no frameworks, no build step.

## What it covers

1. **What is phishing** — how phishing works and why it succeeds
2. **Types of phishing** — email phishing, spear phishing, smishing, vishing, clone phishing and fake websites
3. **Red flags** — the warning signs in a message, link or login page
4. **Do's and Don'ts** — safe habits for email, messages and browsing
5. **Interactive quiz** — 10 scenario-based questions with instant feedback and a final score
6. **What to do if you clicked** — the immediate steps to limit damage and report the attack

## Run it

Open `index.html` in any browser. Everything (training content + quiz) is in this single page, styled by `styles.css` and powered by `quiz.js`.

## Files

- `index.html` — training content and quiz layout
- `styles.css` — page styling
- `quiz.js` — quiz questions, scoring and feedback

## Disclaimer

All example messages, brands and links shown in the training are fictional and created only for education. Never enter real credentials on a page you reached from an unsolicited message.
